3. SPRING SECURITY (SecurityConfiguracao.java)
--------------------------------------------------------------------------------

[x] @EnableMethodSecurity
    Permite uso de @PreAuthorize nos controllers

[x] PasswordEncoder
    Bean: BCryptPasswordEncoder

[x] AuthenticationManager
    Bean configurado para uso no LoginController

[x] CSRF
    Desabilitado (aplicação stateless com JWT)

[x] Session Creation Policy
    STATELESS (não cria HttpSession)

[x] Rotas públicas
    /login → permitAll()

[x] Proteção por método HTTP
    POST /barbeiros/** → hasRole("ADMINISTRADOR")

[x] Demais rotas
    anyRequest().authenticated()

[x] Filtro JWT
    JwtAuthFilter adicionado antes do UsernamePasswordAuthenticationFilter

[x] UserDetailsService customizado
    CustomUserDetailsService injetado

--------------------------------------------------------------------------------
4. AUTENTICAÇÃO E AUTORIZAÇÃO
--------------------------------------------------------------------------------

[x] CustomUserDetailsService
    Busca usuário na ordem: Administrador → Barbeiro → Cliente
    Define role com base no NivelAcesso
    Desabilita usuário se status = INATIVO

[x] JwtService
    Gera token com subject (e-mail) + roles
    Valida token e extrai claims

[x] JwtAuthFilter
    Lê header Authorization: Bearer <token>
    Valida e popula SecurityContext

[x] LoginController
    POST /login
    Autentica com AuthenticationManager
    Retorna token JWT + tipo "Bearer"
