    ___O método .orElseThrow() faz parte da classe Optional no Java (introduzida no Java 8 e aprimorada no Java 10)
    ___e serve para retornar o valor contido no Optional ou lançar uma exceção caso o valor seja nulo/ausente.
    ___Para que serve?
       - Ele elimina a necessidade de checagens manuais com if (optional.isPresent()) ou verificações de null,
       - tornando a leitura do código mais fluida ao tratar a ausência de um dado diretamente como uma exceção de negócio ou infraestrutura.
